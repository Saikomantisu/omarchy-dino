# Dino

![Dino](preview.png)

Chrome's offline dino game in your Omarchy bar. Click the dino icon to play.

## Install

```bash
omarchy plugin add https://github.com/Saikomantisu/omarchy-dino --enable
```

## Remove

```bash
omarchy plugin remove io.github.saikomantisu.dino
```

## Controls

- `Space` or `↑`: jump
- `↓`: duck
- `P`: pause
- `Esc`: close
